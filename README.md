# Vysyo

Lecteur IPTV pour box Android TV et Windows : Xtream Codes, listes M3U / M3U8 et portails Stalker,
guide TV, films, séries, favoris, replay, enregistrements. Vysyo ne fournit **aucun contenu** : il lit
l'abonnement que vous y ajoutez.

## Télécharger

- **Box Android TV / Google TV / téléphone** : `Vysyo.apk` dans la page
  [Releases](https://github.com/RazHalpox/vysyo/releases/latest).
- **Windows** : l'installeur `Vysyo-Setup.exe` dans la même page.

Ensuite, les mises à jour se font depuis l'appli (Réglages › À propos).

## Affiches et résumés

Les fiches des films et séries sont enrichies par TMDB avec **votre propre clé gratuite** :
créez un compte sur themoviedb.org, puis Paramètres › API, et collez la clé dans
Réglages › Sources › Clé TMDB.
